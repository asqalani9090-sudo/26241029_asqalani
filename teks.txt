Menghitung Luas Segitiga,Ipo
IPO (Input, Process, Output)

Input (Masukan)	Process (Proses)	Output (Keluaran)
alas, tinggi	Hitung luas = 0.5 \(\times \) alas \(\times \) tinggi	luas

2. Algoritma (Bahasa Natural)
Algoritma adalah urutan langkah logis untuk menyelesaikan masalah dalam bahasa sehari-hari:
	1.	Mulai program.
	2.	Masukkan nilai alas segitiga.
	3.	Masukkan nilai tinggi segitiga.
	4.	Hitung luas menggunakan rumus: luas = 0.5 * alas * tinggi.
	5.	Tampilkan hasil perhitungan luas.
	6.	Selesai.



3. Pseudocode
Pseudocode adalah representasi algoritma menggunakan kode semu yang mirip dengan bahasa pemrograman.

text
PROGRAM Hitung_Luas_Segitiga

DEKLARASI:
    alas, tinggi, luas : REAL

ALGORITMA:
    READ alas
    READ tinggi
    
    luas <- 0.5 * alas * tinggi
    
    WRITE luas
END
